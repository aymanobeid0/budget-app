# Browsing by Month, with Shared Month Code in Core

We let Home and the Income tab step back through past calendar months, each month showing its total, its entries, and a plain ranked list of what it went to (per Category or Income Source, largest first, tap one to filter). This is a way of reading the entries already logged, not the analytics dashboard ADR 0002 rules out: there are no charts, trends, budgets or insights, and questions beyond "what did that month hold" still go to the Consultant. Because both slices browse the same chosen month, the code they share (`CalendarMonth`, `ChosenMonthCubit`, the month header, the breakdown and its sheet) lives in `lib/core/month/`, a deliberate exception to ADR 0004's lean core; each slice still owns how its own entries are summed and grouped.
