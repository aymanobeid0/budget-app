# Bring-Your-Own-Key AI Providers

The Expense Consultant no longer ships with a Gemini key. Each user connects an AI Provider of their choice (Google Gemini, OpenAI, Anthropic Claude, Groq or OpenRouter) with their own API key, so the app carries no shared secret that could be pulled out of the binary and no AI bill of its own. Keys stay on the device in the OS secure store (Keychain/Keystore), are never synced to Supabase, and survive an account switch because they belong to the person holding the phone. Every provider is called over plain HTTP with one small server-sent-events parser, rather than one SDK per provider, so each adapter is a thin request/response mapping behind `ConsultantClient` and tests pass a fake HTTP client. Testing a key lists the provider's models (free; it also fills the model picker), and saving pings the chosen model with a one-token completion; keys may still be saved untested or failing, and real chat calls keep their status current. Flutter web is not supported for the Consultant, because the only place a browser can keep the key is web storage.
